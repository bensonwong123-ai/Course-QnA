# Q&A 題庫測驗

一個頁面完成全部流程：**勾選課程 → 開始測驗 → 作答 → 提交，即時顯示分數「x / 10」**。純前端，無需伺服器，直接開啟 `index.html` 即可。

| 檔案 | 作用 |
|---|---|
| `index.html` | 唯一的頁面 |
| `quiz.js` | 全部程式：選擇課程、抽題、作答、評分、逐題檢視 |
| `data.js` | 題庫：17 個課程 × 每個課程 20 題（共 340 題），每題附 4 個選項和解釋 |
| `styles.css` | 樣式（支援深色模式） |

## 測驗規則

- 必須勾選至少 1 個課程。
- 共抽 10 題，由所選課程**盡量平均**抽出（輪流從每個課程各抽一題）：1 個課程抽 10 題；3 個課程為 4＋3＋3；超過 10 個課程時，隨機抽 10 個課程各 1 題。
- 題目與選項次序都是隨機的。
- 評分：每題 1 分，答對得 1 分，答錯或未作答得 0 分。提交時不會提示未作答的題目。

## 新增或修改題目

只需改 `data.js`。每個課程有一個 `questions` 陣列：

```js
{ topic: `主題名稱`, q: `問題`,
  a: `答案解釋`,
  o: [`正確答案`, `錯誤選項 1`, `錯誤選項 2`, `錯誤選項 3`] }
```

- `o` 的**第一項必須是正確答案**，測驗時會自動打亂次序。
- 字串用反引號 `` ` `` 包住，內容就可以包含 `"` 引號。
- 為了避免「最長的選項就是答案」，抽題時每題的 3 個錯誤選項，會由該題自己的錯誤選項，加上（最多 1 個）借自同一課程其他主題題目的錯誤選項／同一主題另一題的正確答案組成，並優先選用長度最接近正確答案的選項。若某題借用同主題別題的答案會造成歧義，在該題加上 `solo: true`（同主題的答案既不借用，也不被借用）。

## 儲存的資料

- `qna-courses`（localStorage）：上次勾選的課程
- `qna-quiz`（sessionStorage）：進行中或剛完成的測驗（重新整理頁面不會重新抽題）
